# 深圳燃气

## 先在小程序完成手机号登录

1. 在微信搜索“深圳燃气”，核对服务主体后进入官方小程序。
2. 在首页或“我的”进入登录。若提供微信手机号授权，可按提示授权；若使用短信登录，输入本人手机号、获取验证码并提交。验证码只填在官方小程序，不填 HA。
3. 进入账户/用户绑定入口，按小程序要求填写本人燃气客户号并完成校验；客户号可从自己的官方账单查找。具体入口名称可能随版本变化。
4. 确认小程序已能显示自己的余额、账单或用气记录，再开始抓包。没有绑定账户时，HA 无法凭空发现客户号。

## 安装与 HA 配置

1. 在深圳燃气小程序登录并绑定自己的账户。
2. 安装 `custom_components/shenzhen_gas`，重启 HA，添加“深圳燃气”。
3. 填写小程序请求头的 **CodeId**，以及绑定账户请求中的 **accountChannelId**。
4. 若有多个绑定账户，在 HA 选择需要的账户。

渠道 ID 不是客户号，不保证默认值适合所有账户；请使用自己请求中的值。`acct` / `ccbCustNo` 也不是 CodeId。

## 首次获取凭据

使用 mitmproxy 等工具，仅对自己登录的小程序做 HTTPS 抓包，域名过滤为 `wechat.szgas.com.cn`。
进入账单或余额页，在 `/api/` 请求头查找 `CodeId`；绑定账户的 `receiveBandingAcctIdList` 请求体包含 `accountChannelId`。
不需要把完整抓包交给别人。证书信任和清理要求见[安全说明](security.md)。

接口 access token 与 CodeId 不同：插件会获取接口 access token，但不能承诺 CodeId 永久有效。遇到认证失效先查看 HA 的脱敏日志，再更新自己的配置。

## 数据口径

默认每 30 分钟刷新。余额、上期账单、用气日期、最新读数及日明细取决于表具与接口。
“昨日”按中国时区严格匹配日期；最近一次有记录的数据不冒充昨日。
零用气是有效数据，缺失不是零。阶梯、电池和下一账单日等未确认指标默认禁用。
